เฉลยและคำอธิบายแบบทดสอบ MS Excel Advance & Power BI

คู่มือเฉลยคำตอบพร้อมอธิบายหลักการทำงานอย่างละเอียด ครอบคลุมทั้ง 40 ข้อ (Excel 20 ข้อ + Power BI 20 ข้อ)

📌 ภาพรวมแบบทดสอบ (Assessment Overview)

เอกสารชุดนี้รวบรวมเฉลยอย่างเป็นทางการและคำอธิบายเชิงลึกระดับมืออาชีพ เหมาะสำหรับใช้ทบทวนความรู้ ประกอบด้วย ส่วนที่ 1: MS Excel Advance (20 ข้อ) ที่มุ่งเน้นการใช้อ้างอิงเซลล์ ฟังก์ชันเงื่อนไข การจัดการข้อมูล และ Power Pivot / DAX เบื้องต้น รวมถึง ส่วนที่ 2: Power BI (20 ข้อ) ที่ครอบคลุม Data Cleansing, Data Modeling, DAX, Visualizations และการตั้งค่า Dashboard

ส่วนที่ 1: เฉลยแบบทดสอบ MS Excel Advance (ข้อ 1 - 20) Excel Advanced Core Knowledge
ข้อ 1: ถ้าต้องการดูผลสรุปเบื้องต้น เช่น ผลรวม ค่ามากสุด ค่าน้อยสุดและค่าเฉลี่ย โดยไม่ต้องการพิมพ์สูตร ต้องทำอย่างไร
✓ คำตอบ: ดูผลสรุปได้ที่ Status bar
คำอธิบาย: เมื่อคลุมดำเลือกช่วงข้อมูล แถบสถานะด้านล่างสุดของโปรแกรม Excel (Status bar) จะคำนวณและแสดงผลรวม (Sum), ค่าเฉลี่ย (Average), และจำนวนนับ (Count) ให้ทันทีโดยไม่ต้องเขียนสูตร และสามารถคลิกขวาเพื่อเลือกเปิด/ปิดการแสดงค่า Min/Max เพิ่มเติมได้
ข้อ 2: AutoFill หรือการเติมข้อมูลอัตโนมัติ ทำได้โดย
✓ คำตอบ: คลิกที่มุมขวาของเซลล์ ให้เมาส์เป็นรูปบวก +
คำอธิบาย: การใช้ Fill Handle ทำได้โดยการเลื่อนเมาส์ไปที่มุมล่างขวาของเซลล์ที่เลือก จนเครื่องหมายเมาส์เปลี่ยนเป็นสัญลักษณ์บวกสีดำทึบ (+) จากนั้นคลิกค้างแล้วลากเพื่อคัดลอกสูตรหรือเติมข้อมูลตามอนุกรม
ข้อ 3: การทำซ้ำคำสั่งล่าสุด ใช้คีย์ลัดโดย
✓ คำตอบ: F4
คำอธิบาย: ปุ่มคีย์ลัด F4 ทำหน้าที่สั่งให้ Excel ทำซ้ำคำสั่งล่าสุดที่เพิ่งกระทำไป (เช่น การระบายสีเซลล์ การแทรกแถว) และหากใช้งานขณะกำลังพิมพ์สูตร ปุ่ม F4 จะทำหน้าที่สลับรูปแบบการล็อกเซลล์ ($)
ข้อ 4: การอ้างอิงเซลล์ B$4 หมายถึง
✓ คำตอบ: ไม่ล็อกคอลัมภ์ B ล็อกแถว 4
คำอธิบาย: เครื่องหมาย $ ถูกวางไว้หน้าเลข 4 จึงหมายถึงการล็อกแถวที่ 4 ไว้ไม่ให้เปลี่ยนตำแหน่งเวลาคัดลอกสูตรลงล่าง แต่คอลัมน์ B ไม่มีเครื่องหมาย $ จึงเปลี่ยนได้ตามแนวนอน (Mixed Reference)
ข้อ 5: การอ้างอิงเซลล์ $B$4 หมายถึง
✓ คำตอบ: ล็อกคอลัมภ์ B ล็อกแถว 4
คำอธิบาย: มีเครื่องหมาย $ อยู่ทั้งหน้าคอลัมน์ B และหน้าแถว 4 เป็นการตรึงตำแหน่งแบบสมบูรณ์ (Absolute Reference) ไม่ว่าจะคัดลอกสูตรไปตำแหน่งใด สูตรจะชี้ไปที่เซลล์ B4 เสมอ
ข้อ 6: การอ้างอิงเซลล์ $B4 หมายถึง
✓ คำตอบ: ล็อกคอลัมภ์ B ไม่ล็อกแถว 4
คำอธิบาย: เครื่องหมาย $ อยู่หน้าคอลัมน์ B ทำให้คอลัมน์ถูกล็อกตรึงไว้ แต่แถว 4 ไม่มี $ กำกับ ทำให้แถวเปลี่ยนไปตามแนวดิ่งเมื่อคัดลอกสูตรลงล่าง
ข้อ 7: ฟังก์ชัน COUNTA(E4:E9) ใช้สำหรับ
✓ คำตอบ: นับช่องที่มี "ข้อมูลทุกประเภท"
คำอธิบาย: COUNTA (Count All) ทำหน้านี้นับจำนวนเซลล์ที่มีข้อมูลทุกชนิดที่ไม่ใช่เซลล์ว่าง ทั้งตัวเลข ตัวอักษร สัญลักษณ์ หรือ Error ต่างจาก COUNT ที่นับเฉพาะตัวเลขเท่านั้น
ข้อ 8: ฟังก์ชัน =LARGE(J4:J9, 2) ใช้สำหรับ
✓ คำตอบ: หาค่าที่สูงที่สุดอันดับ 2
คำอธิบาย: ฟังก์ชัน LARGE(array, k) ใช้สำหรับค้นหาค่าตัวเลขที่มีค่ามากเป็นอันดับที่ k ในชุดข้อมูล (ในที่นี้กำหนด k = 2 จึงได้ค่าที่มากที่สุดเป็นอันดับ 2)
ข้อ 9: ฟังก์ชัน =ROUND(K4,2) ใช้สำหรับ
✓ คำตอบ: ปัดให้เหลือทศนิยม 2 ตำแหน่ง
คำอธิบาย: ROUND(number, num_digits) ปัดเศษทศนิยมตามหลักคณิตศาสตร์ โดยกำหนด num_digits = 2 เพื่อให้ผลลัพธ์เหลือทศนิยม 2 ตำแหน่ง
ข้อ 10: ฟังก์ชัน =INT(3450.99) ใช้สำหรับ
✓ คำตอบ: ทำให้เลขเป็นจำนวนเต็ม
คำอธิบาย: ฟังก์ชัน INT จะปัดเศษทศนิยมทิ้งทั้งหมด และตัดลงให้เหลือเฉพาะจำนวนเต็มที่มีค่าน้อยกว่าหรือเท่าเดิม (ในข้อนี้จะได้ผลลัพธ์เป็น 3450)
ข้อ 11: บริษัทต้องการตัดเกรดผลงานพนักงานเป็น A, B, C เพื่อใช้พิจารณาโบนัสปลายปี ควรใช้ฟังก์ชันใด เหมาะสมที่สุด
✓ คำตอบ: IFS
คำอธิบาย: ฟังก์ชัน IFS ออกแบบมาเพื่อทดสอบหลายเงื่อนไขต่อเนื่องกัน เหมาะสำหรับการตัดเกรดโดยไม่ต้องใช้สูตร IF ซ้อนกันหลายชั้นเหมือนใน Excel เวอร์ชั่นเก่า
ข้อ 12: พนักงานจะได้โบนัสก็ต่อเมื่อ "ยอดรวม Q1 ผ่านเกณฑ์ (150,000)" และ "ห้ามมียอดขายตกต่ำกว่า 50,000 บาทแต่ละเดือน" ควรใช้ฟังก์ชันใด เหมาะสมที่สุด
✓ คำตอบ: AND
คำอธิบาย: เงื่อนไขการรับโบนัสระบุว่าเงื่อนไขทุกข้อต้องเป็นจริงพร้อมกันทั้งหมด จึงต้องใช้ฟังก์ชันทางตรรกศาสตร์ AND ร่วมกับเงื่อนไขต่างๆ
ข้อ 13: เราอยากรู้ว่ายอดขายในไตรมาส 1 นี้ มีบิลที่มาจากพนักงาน "ภาคเหนือ" จำนวนกี่ใบ ควรใช้ฟังก์ชันใด เหมาะสมที่สุด
✓ คำตอบ: COUNTIFS
คำอธิบาย: การนับจำนวนรายการ (นับใบบิล) ตามเงื่อนไขตั้งแต่ 2 เงื่อนไขขึ้นไป (เงื่อนไขไตรมาส 1 + เงื่อนไขภาคเหนือ) ต้องใช้ฟังก์ชัน COUNTIFS
ข้อ 14: ฟังก์ชัน VLOOKUP มีหน้าที่
✓ คำตอบ: ค้นหาข้อมูล
คำอธิบาย: VLOOKUP (Vertical Lookup) ทำหน้าที่ค้นหาและดึงข้อมูลจากตารางอ้างอิงตามคีย์ที่กำหนดในแนวตั้ง
ข้อ 15: ข้อเสียของ VLOOKUP คือ
✓ คำตอบ: คอลัมน์คำค้นหาต้องอยู่ซ้ายสุดเสมอ
คำอธิบาย: ข้อจำกัดหลักของ VLOOKUP คือ คีย์หรือค่าที่ใช้ค้นหาต้องอยู่ในคอลัมน์แรก (ซ้ายสุด) ของช่วงข้อมูลอ้างอิงเสมอ ไม่สามารถค้นหาข้อมูลที่อยู่ทางซ้ายของคีย์ค้นหาได้
ข้อ 16: ฟังก์ชัน INDEX และ MATCH มีหน้าที่
✓ คำตอบ: ค้นหาข้อมูล
คำอธิบาย: การนำ INDEX (ดึงค่าตามตำแหน่ง) มาร่วมกับ MATCH (หาตำแหน่งของข้อมูล) ใช้สำหรับค้นหาและคืนค่าข้อมูลอย่างมีประสิทธิภาพสูง และแก้ข้อจำกัดของ VLOOKUP ได้ทั้งหมด
ข้อ 17: ข้อใดไม่ใช่ประโยชน์ Pivot Table
✓ คำตอบ: การอัปเดตข้อมูลต้นฉบับแบบเรียลไทม์อัตโนมัติ
คำอธิบาย: Pivot Table ไม่อัปเดตข้อมูลอัตโนมัติทันทีที่มีการเปลี่ยนแปลงข้อมูลในตารางต้นฉบับ ผู้ใช้งานจำเป็นต้องกดปุ่ม Refresh หรือใช้มาโครสั่งงานเพื่อทำการคำนวณใหม่
ข้อ 18: ข้อใดไม่ใช่กฎการสร้าง Pivot Table
✓ คำตอบ: ข้อมูลต้องเป็นตัวเลขเท่านั้น
คำอธิบาย: ฐานข้อมูลสำหรับสร้าง Pivot Table สามารถประกอบด้วย ข้อความ (Text), วันที่ (Date), หรือค่าตรรกะได้ ไม่จำเป็นต้องเป็นตัวเลขทั้งหมด เนื่องจาก Pivot Table สามารถนำข้อความมาจัดกลุ่มหรือนับจำนวน (Count) ได้เช่นกัน
ข้อ 19: Power Pivot คือ
✓ คำตอบ: เครื่องมือจัดการ Data Modeling
คำอธิบาย: Power Pivot เป็น Add-in ขั้นสูงใน Excel ที่ช่วยจัดการโมเดลข้อมูล (Data Model) รองรับข้อมูลขนาดใหญ่หลายล้านแถว และเชื่อมโยงความสัมพันธ์ระหว่างหลายตารางได้โดยไม่ต้องใช้ VLOOKUP
ข้อ 20: Data Analysis Expressions (DAX) คือ
✓ คำตอบ: เป็นชุดภาษาที่ประกอบด้วยฟังก์ชันและตัวดำเนินการ
คำอธิบาย: DAX คือชุดภาษาฟังก์ชัน คำสั่ง และตัวดำเนินการ ที่ออกแบบมาเพื่อใช้ในการคำนวณวิเคราะห์ข้อมูล สร้าง Calculated Columns และ Measures ทั้งใน Power Pivot และ Power BI
ส่วนที่ 2: เฉลยแบบทดสอบ Power BI (ข้อ 1 - 20) Power BI Desktop & Service
ข้อ 1: นามสกุลไฟล์มาตรฐานของโปรแกรม Power BI Desktop เมื่อทำการบันทึกคือข้อใด?
✓ คำตอบ: ข. .pbix
คำอธิบาย: ไฟล์รายงานหลักที่บันทึกจากโปรแกรม Power BI Desktop จะใช้นามสกุล .pbix (Power BI Executive File) ซึ่งบรรจุทั้ง Data Model, Queries และ Visualizations
ข้อ 2: หากต้องการทำความสะอาดข้อมูล (Data Cleansing) ตัดคอลัมน์ หรือเปลี่ยนประเภทข้อมูลก่อนนำไปสร้างรายงาน เครื่องมือใดใน Power BI ที่ใช้ทำหน้าที่นี้?
✓ คำตอบ: ค. Power Query
คำอธิบาย: Power Query เป็นเครื่องมือทำ ETL (Extract, Transform, Load) หลักใน Power BI ที่ใช้สำหรับการเชื่อมต่อข้อมูล ทำความสะอาด แปลงรูปแบบข้อมูล และตัดคอลัมน์ที่ไม่จำเป็น
ข้อ 3: หน้าต่าง (View) ใดใน Power BI Desktop ที่ใช้สำหรับสร้างและจัดการความสัมพันธ์ระหว่างตารางต่างๆ?
✓ คำตอบ: ค. Model View
คำอธิบาย: Model View (มุมมองแบบจำลอง) ใช้สำหรับบริหารจัดการ Data Model สร้าง จัดการ และดูแผนภาพความสัมพันธ์ (Relationships) ระหว่างตารางต่างๆ เช่น 1-to-Many
ข้อ 4: องค์ประกอบใดของ Power BI ที่เป็นบริการบนระบบคลาวด์ ใช้สำหรับการแชร์รายงานและสร้าง Dashboard เพื่อให้ผู้อื่นดูผ่านเว็บบราวเซอร์ได้?
✓ คำตอบ: ข. Power BI Service
คำอธิบาย: Power BI Service (SaaS คลาวด์ของ Microsoft) ทำหน้าที่เป็นแพลตฟอร์มในการเผยแพร่ (Publish) แบ่งปันรายงาน และสร้าง Dashboard เพื่อการทำงานร่วมกันผ่านเว็บบราวเซอร์
ข้อ 5: "Data Refresh" ใน Power BI มีจุดประสงค์หลักเพื่ออะไร?
✓ คำตอบ: ข. ดึงข้อมูลล่าสุดจากแหล่งข้อมูลต้นทาง เข้ามาอัปเดตในรายงาน
คำอธิบาย: Data Refresh คือการดึงข้อมูลใหม่ล่าสุดจากแหล่งข้อมูลต้นทาง (Data Source) เข้ามาประมวลผลและอัปเดตในรายงาน เพื่อให้รายงานแสดงข้อมูลที่เป็นปัจจุบันเสมอ
ข้อ 6: หากคุณต้องการดู "แนวโน้ม" ของยอดขายที่เกิดขึ้นในแต่ละเดือนตลอดทั้งปี กราฟชนิดใดเหมาะสมที่สุด?
✓ คำตอบ: ค. Line Chart (กราฟเส้น)
คำอธิบาย: Line Chart เหมาะที่สุดสำหรับการนำเสนอข้อมูลอนุกรมเวลา (Time-series data) เพื่อวิเคราะห์แนวโน้ม (Trends) การเติบโต หรือความผันผวนตามลำดับเวลา
ข้อ 7: กราฟชนิดใดเหมาะสมที่สุดสำหรับการแสดง "สัดส่วน" ของยอดขายแบ่งตามภูมิภาคเปรียบเทียบกับยอดขายทั้งหมด (100%)?
✓ คำตอบ: ข. Donut Chart (กราฟโดนัท)
คำอธิบาย: Donut Chart หรือ Pie Chart เหมาะสำหรับการแสดงสัดส่วนเชิงเปอร์เซ็นต์ (Parts-to-whole relationship) ของหมวดหมู่ย่อยเทียบกับภาพรวม 100%
ข้อ 8: หากคุณมีข้อมูลละติจูด (Latitude) และลองจิจูด (Longitude) หรือชื่อจังหวัด และต้องการแสดงยอดขายตามพื้นที่ Visual ใดเหมาะสมที่สุด?
✓ คำตอบ: ค. Map
คำอธิบาย: Map Visual ถูกออกแบบมาเพื่อประมวลผลข้อมูลทางภูมิศาสตร์ (Geographic Data) เช่น ชื่อประเทศ จังหวัด เมือง หรือพิกัด Lat/Long เพื่อนำเสนอในรูปแบบแผนที่
ข้อ 9: หากต้องการเปรียบเทียบยอดขายของพนักงานขายแต่ละคน โดยเรียงลำดับจากคนที่ทำยอดได้มากที่สุดไปหาน้อยที่สุด ควรใช้กราฟใดจึงจะดูง่ายที่สุด?
✓ คำตอบ: ก. Bar Chart (กราฟแท่ง)
คำอธิบาย: Bar Chart (กราฟแท่งแนวนอน) ช่วยให้การเปรียบเทียบความแตกต่างระหว่างหมวดหมู่ที่มีชื่อยาว เช่น ชื่อพนักงาน และการเปรียบเทียบเรียงลำดับมากไปน้อยทำได้ชัดเจนและอ่านง่ายที่สุด
ข้อ 10: Visual ใดใน Power BI ที่ทำหน้าที่เป็น "ตัวกรองข้อมูล" บนหน้าจอรายงาน เพื่อให้ผู้ใช้สามารถคลิกเลือกดูข้อมูลเฉพาะปี หรือเฉพาะแผนกที่สนใจได้?
✓ คำตอบ: ข. Slicer
คำอธิบาย: Slicer คือ Visual ที่ทำหน้าที่เป็นตัวกรองข้อมูลแบบโต้ตอบ (Interactive Filter) บนหน้ารายงาน เพื่อให้ผู้ใช้งานสามารถคลิกเลือกกรองมิติข้อมูลตามต้องการ
ข้อ 11: กราฟใดเหมาะสมที่สุดในการวิเคราะห์ความสัมพันธ์ ระหว่างข้อมูลตัวเลข 2 ตัวแปร เช่น งบโฆษณากับยอดขาย?
✓ คำตอบ: ค. Scatter Chart
คำอธิบาย: Scatter Chart (กราฟกระจาย) ออกแบบมาเพื่อใช้วิเคราะห์ความสัมพันธ์ (Correlation) และการกระจายตัวระหว่างตัวแปรเชิงปริมาณ (Numerical variables) 2 ตัวแปร
ข้อ 12: หากต้องการแสดงตัวเลขสรุปค่าเดียวที่สำคัญมากๆ บนหน้ารายงาน (เช่น ยอดขายรวมทั้งบริษัท) ควรเลือกใช้ Visual ใด?
✓ คำตอบ: ก. Card
คำอธิบาย: Card Visual เหมาะสำหรับการแสดงผลค่าสถิติเดี่ยว (Single metric / KPI) ตัวเลขขนาดใหญ่เพื่อเน้นย้ำความสำคัญ เช่น ยอดขายรวม หรือจำนวนลูกค้ารวม
ข้อ 13: DAX ย่อมาจากอะไร?
✓ คำตอบ: ข. Data Analysis Expressions
คำอธิบาย: DAX ย่อมาจาก Data Analysis Expressions เป็นภาษาที่ใช้สำหรับการสร้างการคำนวณขั้นสูงใน Power BI, Power Pivot และ SSAS Tabular
ข้อ 14: ความแตกต่างที่สำคัญที่สุดระหว่าง Calculated Column และ Measure คืออะไร?
✓ คำตอบ: ข. Column จะคำนวณทีละแถว Measure คำนวณตามบริบทการกรองบนหน้าจอรายงาน
คำอธิบาย: Calculated Column ประมวลผลแบบ Row Context และจัดเก็บค่าลง RAM ทุกแถวในตาราง ขณะที่ Measure จะประมวลผลแบบ Filter Context คำนวณแบบ Dynamic ตามตัวกรองบนหน้าจอรายงานโดยไม่ใช้พื้นที่จัดเก็บเพิ่ม
ข้อ 15: ฟังก์ชัน DAX ใดที่ใช้สำหรับหาผลรวมของค่าตัวเลขในคอลัมน์ที่กำหนด?
✓ คำตอบ: ค. SUM
คำอธิบาย: ฟังก์ชัน SUM ในภาษา DAX ใช้สำหรับคำนวณหาผลรวมของตัวเลขทั้งหมดที่มีอยู่ในคอลัมน์ที่ระบุ
ข้อ 16: ต้องการนับจำนวนแถวทั้งหมดที่อยู่ในตาราง "Sales" ควรใช้ฟังก์ชัน DAX ใด?
✓ คำตอบ: ค. COUNTROWS('Sales')
คำอธิบาย: COUNTROWS ใช้สำหรับนับจำนวนบรรทัดหรือแถวทั้งหมดที่อยู่ในตารางที่กำหนด (Table Argument) โดยตรง
ข้อ 17: ฟังก์ชันใดใน DAX ที่ใช้สำหรับ "นับจำนวนข้อมูลที่ไม่ซ้ำกัน" (เช่น นับจำนวนรหัสลูกค้าที่ไม่ซ้ำกันว่ามีกี่คน)?
✓ คำตอบ: ง. DISTINCTCOUNT
คำอธิบาย: DISTINCTCOUNT ทำหน้านี้นับจำนวนรายการที่ไม่ซ้ำกัน (Unique Value Count) ในคอลัมน์ เหมาะสำหรับนับจำนวนลูกค้า หรือจำนวนบิลที่เป็นเอกเทศ
ข้อ 18: ความแตกต่างที่สำคัญระหว่าง "Canvas background" และ "Wallpaper" คือข้อใด?
✓ คำตอบ: ข. Canvas background เปลี่ยนสีเฉพาะพื้นที่ขอบเขตที่ใช้จัดวางกราฟ ส่วน Wallpaper เปลี่ยนสีพื้นที่ว่างทั้งหมดที่อยู่รอบนอกพื้นที่ทำงาน
คำอธิบาย: Canvas background คือพื้นหลังเฉพาะบริเวณพื้นที่ตรงกลางสำหรับวาง Visuals ส่วน Wallpaper คือฉากหลังภายนอกทั้งหมดที่อยู่รอบนอกผืน Canvas
ข้อ 19: เมื่อแทรกรูปภาพลงใน Canvas background แล้วพบว่ารูปภาพมีสีเข้มเกินไปจนทำให้มองเห็นกราฟหรือข้อมูลได้ไม่ชัดเจน คุณควรปรับแก้ที่การตั้งค่าใด?
✓ คำตอบ: ค. Transparency
คำอธิบาย: การปรับค่า Transparency (ความโปร่งแสง) ช่วยลดความเข้มของภาพพื้นหลัง ทำให้ภาพจางลงและไม่แย่งความโดดเด่นของกราฟข้อมูลบนรายงาน
ข้อ 20: ต้องการสร้างหน้าเพจพิเศษเพื่อให้แสดงผลเป็น "หน้าต่างป๊อปอัป" ขนาดเล็ก เมื่อผู้ใช้นำเมาส์ไปชี้ที่กราฟในหน้ารายงานหลัก คุณต้องเปิดใช้งาน (On) คำสั่งใดในหัวข้อ Page information?
✓ คำตอบ: ข. Allow use as tooltip
คำอธิบาย: การกำหนดให้หน้าเพจทำงานเป็น Report Page Tooltip (หน้าป๊อปอัปรายละเอียด) จะต้องเปิดตัวเลือก Allow use as tooltip ในหมวด Page Information ของหน้านั้นๆ
